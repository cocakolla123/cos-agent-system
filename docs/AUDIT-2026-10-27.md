An outside review of commit 7d78e17 listed the findings below. Each one was
checked against the code before it was fixed. Each fix has a test that fails
on the old code and passes on the new.

## Not done here

- **An OS-level sandbox** for jobs that read untrusted content, beyond Claude Code's tool permissions (for example a container or macOS sandbox profile).
- **The learn job** keeps `Bash(python3:*)` and `Bash(git:*)` because it runs the test suite. It starts only when the user reports a miss in chat, and changes code only when self-modification is on.
- **Packaging:** versioned releases, an app-data directory, and an uninstaller that removes everything.
- **Real-world reliability:** a handful of consenting users on their real accounts, measuring missed obligations, wrong deadlines, duplicates, cost, and trust in the approval queue. The benchmark (five runs on the full world: C1 test 41.4 of 47, range 37 to 45) is synthetic.
