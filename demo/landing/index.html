Benchmark

Score your own agent.
Or train one.

The whole world is code with fixed seeds, so anyone gets the same 142,555 items and the same answer key for 101 tasks. Every task comes in a matched pair: tune on one half, report the other.

01

Get the data

Build it from code, check it against the lock file, and export a plain folder: the first read, the four weekly batches, and the answer key.

02

Run your agent

Any model, any framework. Write the tasks it thinks are open on Oct 13 and on Nov 10 as a JSON list.

03

Score it

The same scorer as this app's own runs: caught, due date, priority, who owes whom, duplicates, workspace leaks, planted instructions.

04

Make it harder

Each task is a short Python function. Write a pair, rebuild, and have a blind labeler check your answers. Or fine-tune on the training split, which only holds the tuning half.

How it works

Three moves, every day.

01

It reads

On a schedule, with no prompt from you. Every inbox, channel, ticket, calendar and doc you connect, cross-checked into one graph of who you owe what, by when.

  • muted channels and group DMs
  • the one ask in a 40-message thread
  • work nobody assigned but is yours
02

It does the work

Not "you should reply to Alex". The reply, written. The fix plan, the outline, the review checklist, and a "still needed?" note for tasks that went quiet.

  • drafts in your own wording
  • blanks marked where only you know
  • ranked by deadline, stakes and recency
03

It waits for your yes

Everything lands on one page. Approve, edit or skip. Nothing is sent, posted or merged until you click. It learns from what you change.

  • one click per task
  • edits teach the next draft
  • filters by type, priority, workspace

Safety

It reads everything.
It sends nothing without you.

Read-only

Background jobs can't send

Research and daily checks hold only read tools. No job running on its own has a send, post or delete tool.

Your click

Every send waits

Emails, Slack replies and PRs sit as drafts until you approve them. You can edit any line first.

Your machine

Runs on localhost

The app and your data stay on your computer. API keys live in a local file only you can read.

Open

Every prompt in the repo

MIT licensed. Read the instructions it follows, the test it is scored on, and the fixes it made.

StandardDaily checks, draftsa solid everyday model
DeepThe first read, learningyour strongest model
